# UTN-TUPaD_OE_SistGestionInventarios

# Sistema de Gestión de Inventarios

## Descripción del proyecto
Proyecto académico desarrollado para la asignatura Organización Empresarial de la Tecnicatura Universitaria en Programación de la UTN.

El proyecto propone el desarrollo de un sistema informático orientado a la gestión de inventarios, con el objetivo de mejorar la organización, el registro y el control de existencias.

## Estado del proyecto
Documentación inicial en desarrollo.
